# Local Video Player · 本地视频放映室

**简体中文** | [English](README.en.md)

一个轻量、离线使用的浏览器视频播放器。把自己的视频放入文件夹，即可按课程和章节浏览、连续播放、调整倍速，并记住上次观看位置。

**本项目和发布包均不附带视频。无需注册、上传文件或连接云服务。** 页面采用暖白、米灰与陶土色，不包含第三方品牌标识。当前界面语言为简体中文。

## 下载与开始使用

1. 打开仓库右侧的 **Releases**，下载 `local-video-player-v1.0.0-windows-x64.zip`。
2. **完整解压**到一个普通文件夹，不要直接在压缩包内运行启动文件。
3. 把自己的视频放进包内的 `videos` 文件夹。
4. 双击 **`Start Player.cmd`**，在系统默认浏览器中使用。

免安装包适用于 **Windows 10 / 11、Intel / AMD 64 位电脑**，内含运行组件，无需单独安装 Python。源码下载中的 `Source code.zip` 不包含运行组件；如果只想直接使用，请下载上面命名的便携 ZIP。

启动后访问地址为 `http://127.0.0.1:18768`。程序只监听本机，不对局域网提供服务。需要结束后台服务时，双击 **`Stop Player.cmd`**；关闭浏览器标签页本身不会结束后台服务。

## 使用已有的视频目录

如果视频已经在其他硬盘上，无需再复制：

1. 用记事本编辑包内的 **`video-directory.txt`**。
2. 把文件内容替换为视频文件夹的路径，例如 `E:\My Videos`。只写一行，不加引号；中文、空格和普通反斜杠均可使用。
3. 保存后启动播放器。如果已经启动，先运行 `Stop Player.cmd`，再重新启动。

相对路径从程序目录计算，默认值为 `videos`。源码运行时配置文件可省略，也可以复制 `video-directory.example.txt` 为 `video-directory.txt` 后编辑。请指定需要播放的目录，不要把整块磁盘当作视频目录。

## 推荐目录结构

```text
videos/
├─ 课程一/
│  ├─ 第1章/
│  │  ├─ 01-介绍.mp4
│  │  └─ 02-基础.mp4
│  └─ 第2章/
│     └─ 01-练习.mp4
└─ 课程二/
   └─ 01-开始.mp4
```

第一层文件夹作为课程，更深层目录作为章节。直接放在根目录的视频归入“其他课程”。课程、章节和课时按文件名中的数字自然排序，因此 `2` 排在 `10` 前面。新增文件后点 **“刷新目录”** 即可，不必重新打包程序。

## 功能

- 按课程、章节选集，以及全库搜索。
- 自动连播，可选当前课程或整个资料库；播放到最后一集会停止。
- 0.5～3 倍速、音量记忆、每集断点续播、已看完标记。
- 原生播放进度条、全屏、宽屏和画中画（依浏览器支持情况）。
- 窄窗口布局及键盘操作。

| 按键 | 操作 |
| --- | --- |
| 空格 / K | 播放或暂停 |
| ← / → | 后退或前进 5 秒 |
| ↑ / ↓ | 调节音量 |
| Shift + ← / → | 上一集或下一集 |
| [ / ] | 降低或提高倍速 |
| F / T / M | 全屏 / 宽屏 / 静音 |
| / | 聚焦搜索框 |

输入框、菜单和按钮获得焦点时，优先保留其本身的键盘操作。空格键会避免与浏览器原生视频控件重复触发；长按空格不会反复暂停和恢复。

## 格式与观看记录

识别 `.mp4`、`.webm`、`.m4v`、`.mov`、`.mkv`、`.ogg`。**扩展名被识别不代表其内部编码一定可播放**，解码能力取决于浏览器。程序不提供转码器，也不修改原视频。

进度、音量和倍速存储在当前浏览器的本地存储中。新电脑或不同浏览器不会自动继承记录，清除站点数据、使用无痕模式或改变访问端口也可能使原记录不可用。视频相对路径参与识别课时；重命名或移动课程会影响对应关系，切换到具有相同相对路径的其他资料库可能沿用原记录。

## 从源码运行

需要 Python 3.10 或以上版本，**运行时不依赖第三方 Python 包**：

```sh
python launch.py --open
```

开发时可以直接以前台方式运行服务，并使用 `Ctrl+C` 停止：

```sh
python player/server.py --root ./videos --port 18768 --open
```

Windows 的启动、停止脚本服务于免安装包；其他系统可以尝试源码命令，但本项目的便携发行版只验证了 Windows x64。`Stop Player.cmd` 只停止由当前解压目录内运行组件启动的播放器。

## 测试与构建

```sh
python -m unittest discover -s tests -v
python scripts/build_portable.py
```

构建脚本下载官方嵌入式运行组件并核对固定 SHA-256，输出纯程序 ZIP 到 `dist/`。可以传入 `--runtime-zip /path/to/runtime.zip` 使用已下载且校验一致的文件。构建脚本按白名单打包，不收录视频、自定义目录配置、个人路径或观看记录。

## 常见问题

- **打开后没有视频**：确认目录配置正确、视频使用支持的扩展名，再点击“刷新目录”。
- **修改目录后启动失败**：先停止旧服务，再启动；不要同时启动使用相同端口的多份程序。
- **页面无法打开**：先运行启动脚本；源码运行时查看终端错误。
- **视频无法解码**：尝试浏览器能够播放的编码，或使用其他播放器打开原文件。
- **更新播放器**：先停止服务，保留自己的视频和 `video-directory.txt`，再更换程序文件。不要用空目录覆盖自己的资料。
